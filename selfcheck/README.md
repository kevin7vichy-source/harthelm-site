# HARTHELM｜家舵 准备度自测 · 离线包

## 这是什么

本机使用的 **高才通 TTPS / 优才 QMAS / 新加坡 EP** 资料准备度自测工具。  
纯静态页面，**不需要安装、不需要联网、不收集邮箱电话**。

由 **HARTHELM｜家舵** 提供，仅供资料整理参考；**不构成法律意见**，**不是**入境处 / 人才办 / MOM 官方系统。

口号：为家掌舵，为业远行。

## 怎么用

1. 解压本 zip（或打开本文件夹）。
2. 用浏览器双击打开 **`index.html`**（Chrome / Edge / Safari / Firefox 均可）。
3. 选择身份入口 → 回答入口问题 → 勾选资料「有 / 无 / 已过期 / 不适用」。
4. 点击「生成缺失清单与准备度」。
5. 可选勾选「在本机保存进度」；不需要时可点「清除本机答卷」。

## 不会做什么

- 不评分、不显示通过率、不报价、不承诺获批  
- 不连接云端或分析脚本  
- 不要求填写证件号、账号明文、薪金数字
